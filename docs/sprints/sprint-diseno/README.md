# Sprint de Diseño

Esta carpeta conserva la revisión documental de los artefactos de diseño y la retrospectiva basada en evidencia disponible.

| Documento | Propósito |
|---|---|
| [Review](review.md) | Resume los artefactos revisados y decisiones necesarias para continuar. |
| [Retrospective](retrospective.md) | Registra observaciones, riesgos de trazabilidad y acciones aplicadas al proyecto. |
| [Registro de la sesión 6](registro-sesion-6.md) | Fuentes revisadas, confirmaciones que sí constan y límites de la evidencia de Discovery. |
| [Diseño consolidado](../../diseno/README.md) | DER/MER, DDL, mockups, secuencias y exportaciones UML. |
| [Reconciliación DER](../../diseno/reconciliacion-der.md) | Compara el DER de referencia con el esquema Flyway vigente. |

La carpeta de diseño contiene artefactos funcionales; este registro no afirma que todas las decisiones se tomaran antes de comenzar la implementación ni que cada mockup tenga aprobación individual archivada.
