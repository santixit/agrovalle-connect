# Definition of Done

Una historia solo puede pasar a Done si cumple todos los puntos. El equipo firma esta declaracion al aplicarla en cada Pull Request.

- [ ] La rama se actualizo desde `main` y no contiene conflictos.
- [ ] El proyecto compila con Java 17 y `mvn clean verify` termina correctamente.
- [ ] `mvn checkstyle:check` termina sin advertencias.
- [ ] Las pruebas unitarias e integradas existentes pasan; se agregaron pruebas para el cambio.
- [ ] Se mantiene o mejora la cobertura objetivo de 60% en JaCoCo cuando aplique.
- [ ] Se validaron criterios Given-When-Then de la historia.
- [ ] Se aplicaron principios MVC, SOLID y nombres claros.
- [ ] README, BACKLOG y/o documentacion tecnica se actualizaron si corresponde.
- [ ] Los commits siguen Conventional Commits y el hook de Husky paso.
- [ ] Existe Pull Request con revision y aprobacion de al menos un integrante distinto al autor.
- [ ] El flujo de GitHub Actions esta en verde antes de fusionar.
