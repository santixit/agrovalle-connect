# Entregables del curso

Esta carpeta conserva los paquetes preparados para cortes y sprints. Son copias históricas de entrega; no reemplazan el código ni la documentación vigente del proyecto.

| Paquete | Contenido |
|---|---|
| [Sprint 0](sprint-0/README.md) | PDF original de la entrega de infraestructura inicial. |
| [Segundo corte](segundo-corte/README.md) | PDF, generador y anexos de calidad/diseño conservados con el contexto de su fecha. |

## Conservación y privacidad

- El PDF del segundo corte es un artefacto de la entrega realizada y no se modifica para reflejar cambios posteriores del producto.
- Los reportes HTML/ZIP de JaCoCo se mantienen junto a ese paquete porque documentan commits y ejecuciones específicos.
- Los identificadores personales, credenciales, tokens y cadenas de conexión no se agregan a entregables públicos. Los datos de ejemplo deben ser sintéticos.
- Para consultar el estado vigente, usa el [índice de documentación](../README.md), no el estado congelado de un paquete anterior.
