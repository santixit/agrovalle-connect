## Límites de esta bitácora

No se conserva aquí un registro verificable de mensajes privados ni de conversaciones externas al repositorio. Los enlaces de GitHub muestran cambios técnicos y su cronología, no la fecha de Sprint Discovery, una aceptación oral, una reunión o una asignación de roles.

Para registrar acuerdos futuros, el equipo puede usar una nota en un issue o PR con fecha de registro, participantes que confirmen el contenido y decisión tomada. La asignación de tareas se hará por elemento de trabajo, sin cargos permanentes.
