## Criterio de uso

El Backlog BDD es la fuente para historias y comportamiento observable. La SRS agrupa requisitos del sistema. Las decisiones de línea base fijan los límites actuales del prototipo. Un cambio funcional debe actualizar juntos BDD, contrato, modelo, pruebas y trazabilidad en un Pull Request.

La SRS es una línea base de trabajo y no una firma colectiva. Tampoco acredita aceptación funcional de HU-02, HU-06, HU-09 o HU-10; el estado de esas historias se registra en la [review de Sprint 3](../sprints/sprint-3/review.md).
